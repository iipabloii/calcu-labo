Cómo usar y guardar en tu Celular / iPad

Guía práctica para iOS y Android

⚠️ ¿Por qué no aparece "Abrir con Safari" en el iPad / iPhone?

Es una restricción de seguridad de Apple: Safari en iOS no permite abrir archivos locales desde la app de Drive o Archivos. Además, la "Vista Rápida" de Apple desactiva todo el código interactivo (JavaScript).

1 Para iPad / iPhone (Archivos locales sin internet):
  1. Instala la app gratuita Documents de Readdle (o Chrome) desde la App Store.
  2. En Google Drive, toca los tres puntos (…) del archivo → Abrir con... → Elige Documents.
  3. ¡Listo! Funciona de inmediato de forma 100% interactiva, fluida y sin conexión.
2 Para tenerla como App en la Pantalla de Inicio con Safari:

Safari sí puede crear accesos directos de pantalla completa a partir de enlaces web. Si subes el archivo HTML a un host gratuito estático (como tiiny.host o Netlify Drop):

  1. Abre ese enlace en Safari en tu iPad o iPhone.
  2. Toca el botón Compartir (icono de cuadrado con flecha hacia arriba).
  3. Selecciona "Agregar al inicio".
  4. Se creará un icono que abre la calculadora a pantalla completa como una aplicación nativa.
3 En Teléfonos Android (Chrome):

Descarga el archivo HTML → Ábrelo con Chrome → Toca los 3 puntos (⋮) → "Agregar a la pantalla principal".
